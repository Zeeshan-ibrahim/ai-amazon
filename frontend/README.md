# Frontend

Next.js 15 (App Router) + TypeScript + Tailwind CSS.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Requires the backend on port 4000. Point elsewhere with `NEXT_PUBLIC_API_URL`
in `.env.local`.

Structure and conventions: [../docs/architecture.md](../docs/architecture.md).
Tokens and primitives: [../docs/design-system.md](../docs/design-system.md).
